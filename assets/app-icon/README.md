# OpenArt app icon

The image in `openart-source.png` was provided by the project owner. The app uses it for the web
favicon and native Windows, macOS and Linux icons.

## Files

Icon filenames retain their historical `filmcraft` names because build scripts and platform
packaging still refer to them. The displayed product name and icon are OpenArt.

- `openart-source.png`: original user-provided image.
- `filmcraft.svg` and `filmcraft-small.svg`: SVG wrappers embedding the source image.
- `filmcraft-1024.png`, `filmcraft-macos-512.png`, `filmcraft.ico` and `filmcraft.icns`: native app
  icon variants.
- `hicolor/`: Linux icon-theme variants.
- `../../apps/filmcraft-web/web/favicon.png`: browser favicon.

The icon and its derivatives are attributed to the project owner in `ATTRIBUTION.md`. Permission is
for use in this OpenArt repository; no broader license is asserted.
